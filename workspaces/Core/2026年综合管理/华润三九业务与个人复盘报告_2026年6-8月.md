### 3.1 业务核心事实与结果

| 维度      | 事实数据                                              |
| ------- | ------------------------------------------------- |
| 三大KA整体  | 26年目标8322万（+30%），上半年完成3894万（进度47%，同比+40%）         |
| 广佛海王    | 上半年仅79万，进度30%，同比**-64%**，核心是资金周转问题                |

| 益血生/益血生 | 广东上月约1800盒，仅茂名有动销；益血生复购极低，占比仅1-4%                 |

### 3.2 业务问题清单（分层）

**A. 产品结构层（最深层、最难解）**
1. **老品无造血**：益血生、维D等老品高度依赖连锁"推力"，一旦停止政策投入，销量立刻断崖——没有品牌拉力、没有复购留存。
2. **效期积压**：维D已连续两年处理效期，益血生长期处理效期，被大森林列为高危淘汰对象。
3. **新品被透支**：区域为冲指标透支新品价值链，导致新品生命周期极短，"重新品轻老品"的恶性循环。

**B. 价格与渠道层**
4. **价格竞争力弱**：益血生底价47.4元（客户要30元起步），维D原底价47.4元（连锁要求降到30元左右），被双金、星沙、达英及大森林自有品牌低价围剿。
5. **战略厂家费用争议**：大森林抱怨三九"纯投入少、多项目置换且拖欠、合同苛刻"，且存在架构调整导致单方面涨价打乱连锁降本统筹。
6. **总部与分部系统未拉通**：政策靠红头文件下发，分部有操作空间，易致价格体系混乱。

**C. 客户关系层**
7. **海王资金链问题**：常规断货、活动无法落地、核心品类萎缩，业绩缺口最大。
8. **大森林货架优化威胁**：以"动销率低"为由，要求降价或给稳定年度政策，否则清场替换。

### 3.3 已验证的增长因素（能持续复制的）

1. **"钙+D"关联销售策略**：通过"培训→专区陈列→场景话术→过程追踪→关联单激励"的标准化闭环，把钙D关联率从 9% 拉到 13%，动销门店关联率增长 162%。**这是目前最扎实、最可复制的方法论。**
2. **东方红"驻店晒单"模式**：从"单品加提"改成"门店备案制+费用下放到店员"，产出从 426盒 → 812盒 → 4502盒（3个月翻10倍）。关键在**费用及时到店员手上 + 任务拆解到人**。
3. **数据自动化**：一键汇总脚本 + SOP，把重复性数据工作从小时级降到分钟级，释放时间到一线。

### 3.4 业务瓶颈定位（判断）

当前业务真正卡在**"老品的造血能力"**上，而不是"活动做得不够多"。
- 证据：活动一直在做、产出也在涨，但维D/益血生/益血生的底层问题是"没有自然销量 + 复购缺失"，本质是产品力与消费者心智问题。
- 因此，短期靠政策/降价能止血，长期必须靠**品牌教育（钙D同补认知）+ 品类组合（骨健康/干眼等新品类）**来建立自然动销。

## 六、从过去学到什么（经验教训）

1. **"做了很多事"≠"产生了结果"**：6-8月做了大量活动、跑店、数据工作，但真正能沉淀为"可复用资产"的只有三样——钙D方法论、东方红晒单模式、数据自动化。其余多是消耗型执行。
2. **费用/激励的"最后一公里"决定成败**：5月备案制失败 vs 6月驻店晒单成功，唯一变量是"费用有没有及时到店员手上、任务有没有拆到人"。**激励机制的颗粒度，比激励总额更重要。**
3. **AI是杠杆，不是拐杖**：AI 帮你把 PPT/数据/视频提效，但一旦用它替代思考（智创、竞品分析），产出就"不接地气"。**判断力必须自己练，AI 只做执行放大。**
4. **谈判的本质是"长期关系 > 一次价格"**：大森林嘴上要降价，实际要的是"稳定年度政策 + 长期合作"。陈总/吴总的破局点不是砍价，而是"资源打包 + 拉通明年年底"。**客户要的是确定性，不是最低价。**
5. **窗口期的事不能拖**：秋招只有一次，AI红利期也就几年，雅思/升学看板拖14天，代价可能是错过整个提前批。**关键节点要用"倒计时"而不是"有空再做"。**
6. **浮躁是所有问题的放大器**：从挂科、计划中断到时间浪费，根源都是"沉不下心"。**先静心，再谈效率、再谈战略。**

## 七、可复用知识点 / 方法论（沉淀进资产库）

### 知识点1：钙+D关联销售的"五步闭环"
`启动培训（讲透"钙D同补吸收逻辑"）→ 专区陈列（维D放钙剂旁）→ 场景话术（儿童长高/老人抽筋）→ 过程追踪（每日复盘成交小票）→ 关联单激励（考核"钙D关联单数"而非单品销量）`
- 金句：不是多卖一盒D，是帮顾客解决吸收的根本问题。

### 知识点2：东方红"驻店晒单"激励机制设计
- 模式：门店备案制 + 单店指标 + 单盒加提 + PK奖励 + 团建基金。
- 核心三原则：①费用下放到店员（不沉淀在中间）②及时性强 ③任务拆解到人。
- 数据验证：426盒→812盒→4502盒。

### 知识点3：医药零售大KA谈判策略
- 客户要"确定性"（稳定年度政策、长期协议），不要"一次性优惠"。
- 破局靠"资源打包"（加盟铺货+慢病包+贴牌差异化）而非单纯砍价。
- 面对"货架优化/清场"威胁，用"降底价换长期合作空间"的以退为进策略。

### 知识点4：数据自动化的正确姿势
- 重复性工作（表格更新）先建立 SOP + 一键脚本，再优化，不要每次手工重做。
- 历史脏数据要一次性清理 + 统一口径，否则会反复污染。

### 知识点5：职场商务规范（这次踩的坑）
- 敬酒有主次、不越位；给领导/客户叫车级别要匹配；PPT 开场先自我介绍。
- 这些"细节"是实习生最容易暴露、也最容易扣分的点。
