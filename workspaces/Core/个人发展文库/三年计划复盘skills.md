# 一、总报告建议采用的结构

## 0. 执行摘要：先回答“这三年到底怎么样”

这一部分不要一开始就陷入细节，而是先形成一张“三年发展画像”。

建议回答：

1. 三年前的我是什么状态？
2. 现在的我是什么状态？
3. 三年最大的变化是什么？
4. 三年最重要的几个转折点是什么？
5. 三年真正积累下来的核心资产是什么？
6. 哪些投入产生了明显回报？
7. 哪些投入回报低甚至是负的？
8. 当前最大的优势是什么？
9. 当前最大的短板是什么？
10. 当前最应该做的三件事是什么？
11. 如果继续沿着原来的路径走，未来三年可能怎样？
12. 如果重新设计，未来三年应该怎样？

最后形成一句：

> **2023.09 → 2026.08，我从什么人，经过什么事情，形成了什么能力和资产，现在处于什么位置，接下来应该成为怎样的人。**

# 二、第一部分：三年历史发展总览

这是整份报告的“历史纪录片”。

## 1. 三年时间轴

严格按照：

### 第一阶段：大一

**2023.09—2024.08**

重点分析：

- 当时的个人状态
- 进入大学后的环境变化
- 最初目标
- 最初认知
- 做了什么
- 尝试了什么
- 获得了什么
- 遇到了什么问题
- 哪些事情成为后续发展的种子

### 第二阶段：大二

**2024.09—2025.08**

重点分析：

- 相比大一发生了什么变化
- 能力有没有形成
- 兴趣/方向有没有变化
- 开始在哪些事情上形成优势
- 哪些事情开始进入正反馈
- 哪些事情被放弃
- 有没有出现关键转折

### 第三阶段：大三

**2025.09—2026.08**

这是最重要的一年。

分析：

- 大三相比前两年的升级
- 认知变化
- 能力变化
- 项目/实践变化
- 人际与资源变化
- 对未来职业/人生方向的判断变化
- 哪些事情开始真正产生结果
- 哪些问题持续存在
- 哪些问题已经解决

### 三年总体演化

最后不要按照年份写，而是按照：

> **起点 → 探索 → 分化 → 聚焦 → 形成能力 → 形成资产 → 当前定位**

重新解释一遍。

# 三、第二部分：三年“重大事件史”

不要只统计做过什么，要找出真正改变轨迹的事件。

把知识库里的所有重要事件分成：

### A类：战略级事件

对未来方向产生重大影响。

例如：

- 选择专业/方向
- 进入某个行业
- 某次实习
- 某个重要项目
- 某个重大成果
- 某次失败
- 某个关键人物出现
- 某次认知突破
- 某次人生决策

### B类：成长级事件

对能力、习惯、认知产生影响。

### C类：普通事件

发生了，但没有明显改变长期轨迹。

最终形成：

**三年Top 10关键事件**

并回答：

> 如果删掉这10件事中的某一件，后面的我会不会明显不同？

这一步非常重要，因为它能找到真正的**人生转折点**。

# 四、第三部分：三年目标完成度审计

这是从“回忆”进入“复盘”。

把2023年制定过的目标全部找出来。

建立：

|目标|原始目标|实际结果|完成度|超额/不足|原因|后续价值|
|---|---|---|---|---|---|---|

然后不要只统计完成率。

要进一步分析：

### 1. 哪些目标完成了？

为什么？

### 2. 哪些目标没有完成？

为什么？

拆成：

- 目标本身不合理
- 执行不足
- 时间不足
- 能力不足
- 资源不足
- 认知变化
- 外部环境变化
- 中途发现目标不值得做

### 3. 哪些“没完成”的目标实际上应该庆幸没完成？

这是非常重要的一层。

因为：

> **目标完成 ≠ 决策正确。**

### 4. 哪些没有写进计划的事情，反而成为三年最大的收获？

这能发现：

> **计划外成长。**

# 七、第六部分：时间与精力投资回报率

这一部分很容易被普通复盘忽略，但其实非常有价值。

把三年时间投入分类：

- 学业
- 项目
- 实习
- 社团
- 比赛
- 娱乐
- 游戏
- 社交
- 阅读
- 技能学习
- 健身
- 兴趣
- 无效消耗

然后分析：

> **时间投入 → 能力增长 → 成果 → 长期价值**

最终把事情分成四类：

### 第一象限：高投入、高回报

继续加码。

### 第二象限：低投入、高回报

重点寻找机会扩大。

### 第三象限：高投入、低回报

重点优化。

### 第四象限：低投入、低回报

考虑删除。

这一步最终服务于未来三年：

> **不是简单“更加努力”，而是重新配置时间。**

# 八、第七部分：三年的选择与决策复盘

把重要决策全部提出来。

例如：

- 为什么选择这个方向？
- 为什么参加某个项目？
- 为什么放弃某件事？
- 为什么选择某个机会？
- 为什么没有选择另一个机会？

然后分析：

### 决策质量

当时：

> 信息 → 判断 → 选择 → 行动 → 结果

现在回头：

> 当时判断正确吗？

把决策分成：

- 正确决策
- 错误决策
- 信息不足下的合理决策
- 幸运决策
- 运气不好但决策本身正确
- 当时合理、现在已经不适用的决策

这样能避免一个常见错误：

> **用今天的信息去苛责三年前的自己。**

# 十九、给知识库调用的核心分析方法论

你后面调用知识库时，我建议不要只给它一个“总结我的三年”。

而是让它按照下面这套 **Multi-dimensional Personal Development Audit Framework** 工作。

## Skill 1：时间轴重建

**目的：**

把知识库中的所有信息按照真实时间重新排序。

### 方法

`事件 → 时间 → 背景 → 行动 → 结果 → 影响 → 后续`

特别注意：

> **不能因为某条信息后来发生，而倒推它当时已经知道。**

要保持当时的信息状态。

---

# Skill 2：事件重要性评分

每件事情按照：

**Impact × Duration × Irreversibility × Learning × Future Influence**

评分。

寻找真正的关键事件，而不是简单罗列经历。

---

# Skill 3：目标—行动—结果分析

建立：

**Goal → Action → Output → Outcome → Learning**

区分：

- 做了什么
- 产出了什么
- 最终结果是什么
- 长期价值是什么

尤其防止：

> “参加过某项目” = “项目产生了价值”

两者不能画等号。

---

# Skill 4：因果链分析

任何重要结果都追问：

> 为什么？

继续追问：

> 为什么？

直到找到：

**表层事件 → 行为 → 能力 → 认知 → 环境 → 底层原因**

例如：

> 项目失败  
> → 执行不好  
> → 为什么执行不好？  
> → 优先级不清  
> → 为什么优先级不清？  
> → 目标过多  
> → 为什么目标过多？  
> → 缺乏取舍机制

最后找到真正的问题。

---

# Skill 5：能力成熟度模型

每项能力不要简单判断“有/没有”。

采用：

**0 = 不具备**

**1 = 了解**

**2 = 能完成**

**3 = 稳定完成**

**4 = 独立解决复杂问题**

**5 = 可以形成优势/帮助别人**

然后比较：

> 2023 → 2024 → 2025 → 2026

寻找真正成长最快的能力。

---

# Skill 6：个人资产模型

所有三年经历转化成：

**Experience → Skill → Evidence → Reputation → Opportunity**

例如：

一段经历

↓

形成能力

↓

形成作品

↓

形成可信度

↓

产生下一次机会

这就是个人发展的**复利链条**。

---

# Skill 7：ROI分析

对重要活动分析：

**Time Cost → Energy Cost → Financial Cost → Opportunity Cost**

对比：

**Short-term Return + Long-term Return + Option Value**

特别加入：

> **机会成本**

因为大学最稀缺的不是钱，而是时间和注意力。

---

# Skill 8：反事实分析

这是高级复盘非常重要的方法。

针对重大选择问：

> 如果当时没有做这件事，现在会怎样？

> 如果当时做了另一种选择，现在会怎样？

> 如果提前一年做，会怎样？

> 如果晚一年做，会怎样？

用来判断：

**哪些事情真正改变了人生轨迹。**

# Skill 10：贝叶斯式认知更新

不要问：

> “我现在认为自己适合什么？”

而是问：

> **三年前我对自己的判断是什么？**
> 
> **经过哪些现实证据？**
> 
> **哪些判断被证实？**
> 
> **哪些被证伪？**
> 
> **哪些仍然未知？**

形成：

**Hypothesis → Evidence → Update**

这样才能真正找到：

> **我究竟知道自己什么，以及还不知道自己什么。**

# Skill 11：SWOT + TOWS

不是单纯列优势劣势。

而是最终转化成策略：

**S × O → 增长战略**

**S × T → 防御战略**

**W × O → 补强战略**

**W × T → 风险规避**

# 二十、最重要的一条：知识库调用不要一次性让它“写报告”

我非常建议你后面按照**分层调用**来做。

### 第一轮：只做历史重建

让知识库：

> **不要评价，不要总结，不要规划，只负责还原2023.09—2026.08的完整事实。**

输出：

**Timeline + Events + Projects + Goals + Results**

---

### 第二轮：做发展分析

再让它：

> 基于第一轮事实，分析三年发生了什么变化。

输出：

**能力 / 成果 / 认知 / 资源 / 方向 / 问题**

---

### 第三轮：做深层复盘

重点做：

**因果 + 模式 + 决策 + ROI + 失败 + 机会成本**

---

### 第四轮：做当前定位

锁定：

> **2026.08的我到底处于什么位置。**

---

### 第五轮：才做未来

基于前四轮结果：

> **制定2026.09—2029.08的三年战略。**

这样出来的结果会比“直接总结三年并制定未来计划”靠谱很多。
