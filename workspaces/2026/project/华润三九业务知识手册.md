# 华润三九医药零售业务知识手册
### （基于华润三九业务数据库 · 6—8月材料归纳）

> 用途：把谈判、需求、打法、活动安排、专业术语、待补知识点系统梳理成一份可反复查阅的手册。

## 一、专业术语速查（先搞懂这些"黑话"）

| 术语                | 含义                               | 业务中的用法                  |
| ----------------- | -------------------------------- | ----------------------- |
| **动销率**           | 有销售的SKU/门店 ÷ 总数，衡量"货卖不卖得动"       | "维D动销率要提到60%以上"         |
| **铺货率**           | 已铺货门店 ÷ 目标门店总数                   | "广东维D铺货率71%"            |
| **关联率**           | 买A商品的顾客中，同时买B的比例                 | "钙D关联率9%→13%"           |
| **购进 vs 纯销（实销）**  | 购进=连锁从厂家进货（压到渠道）；纯销/实销=终端真正卖给消费者 | 购进高但纯销低 → 效期积压          |
| **效期积压**          | 货卖不动、临近过期                        | 维D连续两年处理效期              |
| **价值链**           | 底价→开票价→零售价之间的利润分配链               | "新品被透支价值链"              |
| **底价 / 开票价 / 返利** | 底价=给经销商的结算价；开票价=票面价；返利=后返政策      | "医学生底价47.4，开票价57+后返9.6" |
| **地采供货**          | 由当地商业公司/配送商供货（而非厂家直供）            | 海王"全面转地采供货"             |
| **O2O**           | 线上下单 + 门店配送（美团/京东）               | "O2O维D动销""O2O组包"        |
| **加提**            | 额外提成激励                           | "单品加提"                  |
| **备案制**           | 门店报备 + 单店指标管理                    | 东方红5-6月合作模式             |
| **贴柜**            | 厂家人员驻店，站柜台旁带教店员卖货                | "200场贴柜"                |
| **晒单**            | 店员晒成交小票换激励                       | "驻店晒单"                  |
| **周爆破**           | 聚焦一周集中资源冲量                       | 广佛周爆破目标27000盒           |
| **百日会战**          | 100天集中攻坚的长期战役                    | 大森林提出的项目                |
| **贴牌（OEM）**       | 找代工生产、贴自己品牌                      | "维D做80粒贴牌差异化"           |
| **统采 / 集权**       | 连锁总部统一采购，分部无自主权                  | 大参林集权后分部活动难落地           |
| **组包**            | 多品种打包销售                          | "钙+D组包"                 |
| **患教**            | 患者教育（科普+检测+互动）                   | 地推炒店+患教                 |
| **首推 / 定级**       | 连锁给商品定的推荐级别（A0/A1/P6）            | "定级A0，5%提成"             |

## 二、谈判知识（从大森林谈判实战提炼）

### 2.1 谈判的本质认知
> 客户（连锁）要的从来不是"最低价"，而是"**确定性**"——稳定的年度政策、长期的合作预期。

### 2.2 大森林谈判的五个关键点
1. **以退为进**：面对"降价否则清场"的威胁，策略是"主动降价 + 同步提要求"，用降价换长期合作空间。
2. **资源打包替代单纯砍价**：当底价降不动时，用"加盟铺货 + 慢病资源包 + 贴牌差异化"等非价格资源快速回补。
3. **找到真正的决策者与诉求**：老板重"长久关系"而非"一次费用"，所以签"拉通明年年底"的长约比一次性让价更有效。
4. **认清自己的位置（信息差）**：三九是"二手房东"，价格天然劣于达英/双金这些"一手贴牌"，所以只能靠"品质 + 终端团队"打动客户，而不是拼价格。
5. **设定谈判节奏**：西普会（8.14）前线上给初步答复 → 会后当面谈定大合同，用节奏制造推进压力。

### 2.3 谈判中可复用的策略
- **锚定与让步**：客户开口要底价30元（锚定），实际预估40元起步（让步空间）——先摸对方锚点再给底线。
- **以品种为抓手，而非单纯卖货**：客户愿意为"能带来终端团队 + 动销能力"的供应商让步。
- **把价格争议转成合作议题**：不谈"降多少"，谈"给什么政策、拉多长周期、配什么资源"。

## 三、需求识别（客户需求 vs 消费者需求）

### 3.1 连锁客户（B端）的核心需求
| 需求 | 具体表现 |
|---|---|
| 动销率 | 货架不能压死货，要有自然销量 |
| 毛利率/毛利空间 | 要50%+的成交毛利 |
| 稳定政策 | 要年度政策（理想5年），反对一季度一签 |
| 费用清晰及时 | 战略费及时到账、合同及时签 |
| 终端团队配合 | 要厂家派团队做动销，不只靠自然增长 |
| 货架资源优化 | 动销差的品种被清场替换 |

### 3.2 消费者（C端）的核心需求
| 品类 | 消费场景/需求 |
|---|---|
| 钙 + 维D | 儿童长高、老人抽筋/骨质疏松 → "补钙不补D，吸收打折扣" |
| 玻璃酸钠（干眼） | 手机不离手/熬夜 → 干眼、眼疲劳，要"不含防腐剂、可用12周" |
| 消痔软膏（肛肠） | 职场白领久坐 → "清凉舒服" |
| 益血生（滋补） | 气血不足 → 复购逻辑未跑通 |

### 3.3 需求识别的关键洞察
- **消费者存在"有症状不用药、用错药、依从性差"** → 品类教育空间巨大，这也是学术驱动打法的底层依据。
- **B端和C端需求要同时满足**：光有C端需求（产品好）但B端没利润/没动销，一样卖不动。

## 四、打法体系（他们的核心打法）

### 4.1 钙+D关联销售（五步闭环，已验证）
`启动培训 → 专区陈列 → 场景话术 → 过程追踪 → 关联单激励`
- 结果：钙D关联率 9%→13%，动销门店关联率 +162%。
- 本质：**把"卖单品"变成"卖组合"**，用存量顾客的组合购买提升客单价和动销。

### 4.2 东方红"驻店晒单"模式（代理商动销）
- 核心三原则：**费用下放到店员 + 及时性强 + 任务拆解到人**。
- 结果：426盒 → 812盒 → 4502盒（3个月翻10倍）。
- 失败反例：5月备案制因"费用没完全下放到员工"效果不佳。

### 4.3 三级营销矩阵（总部+省区+电商）
- **总部**：月度大促（2件75折，7-10天）+ 主题陈列拉动转化。
- **省区**：周爆破 + 考核激励 + 达标奖励驱动门店冲量。
- **电商**：钙+D组包 + O2O联动，拓展线上增量。
- 一句话：**总部给政策、省区给执行、电商给增量，三层协同**。

### 4.4 大单品切入 + 品类共建（新品类打法）
- 以玻璃酸钠（干眼）为突破口，跑通"眼表高频增长模型"。
- 逻辑：**需求端扩容（消费者认知提升）+ 供给端提效（品牌共建、毛利优化、连锁运营）**。

### 4.5 学术驱动（建立专业壁垒）
- 联合协会/专家发布《干眼早发现白皮书》、引用专家共识。
- 配干眼检测仪、理疗仪等"医院同款"设备做信任背书。
- 逻辑：**用专业建立心智，让消费者/店员"信"而不是"推"**。

### 4.6 渠道管控（价格护城河）
- B/C端禁网、O端可挂网；O2O设最低价；一天一巡查、低价链接动态清零。
- 目的：**保护价格体系，防止窜货乱价透支价值链**。

### 4.7 标杆门店复制
- 选高关联门店 → 提炼人员动作 → 拍陈列/小票实证 → 形成宣导手册 → 低关联门店对标带教。

### 4.8 加盟商/贴牌差异化
- 加盟商是"增量机会"；贴牌（80粒维D、400/800单位）做差异化避开价格战。

## 五、活动安排与节奏

### 5.1 按时间维度的活动类型
| 类型 | 节奏 | 举例 |
|---|---|---|
| 月度大促 | 每月7-10天 | 2件75折 |
| 周爆破 | 聚焦一周 | 广佛周爆破目标27000盒 |
| 百日会战 | 100天战役 | 大森林提出、Q4为主战场 |
| 季度战役 | 5-7月/7-9月 | 玻璃酸钠&消痔战役、高济品类攻坚 |
| 大型路演+地推 | 阶段性 | 购进百盒核心店配路演，50盒以上配地推炒店 |
| 患教活动 | 配合活动 | 专家科普、检测、互动 |

### 5.2 一场活动怎么搭（以奥园广场专场为例）
1. **主题定位**："999澳诺成长加油站"。
2. **多方协调**：顾客引流 + 协调大参林/昊泽/乐创三方 + 动线指引 + 素材拍摄。
3. **成本控制**：中医理疗成本 6000→900 元（谈判压价）。
4. **资源联动**：社群26+推5000人、公众号42万粉丝、小红书、视频号直播、异业合作70+家庭。

### 5.3 活动的关键原则
- **活动要平衡"利益"与"熟人经济"**（熟人资源不能只薅一次）。
- **每次活动后15天内交复盘报告**，否则影响报销（费用审批与产出挂钩）。
- **费用申请必须附产出预估、使用路径、复盘报告**（KPI严格挂钩）。

## 六、需要补充的知识点（你的知识缺口）

### 6.1 商业/财务底层
1. **毛利、返利、费用率、ROI 的测算**——现在看数据但未必会算"这个活动到底赚不赚钱"。
2. **价值链设计**——为什么底价、开票价、零售价这样定，贴牌和直营的利润结构差异。

### 6.2 行业与政策
3. **药品流通法规**（两票制、集采、医保统筹、挂网规则）——影响"禁网管控""地采供货"的底层逻辑。
4. **连锁药店经营逻辑**（坪效、货架管理、SKU管理、价格带）——理解客户为什么这么决策。

### 6.3 竞品深度分析
5. **双金、星沙、达英、海露、马应龙**等竞品的价格、渠道、心智打法——现在只有零散感知，没有系统对比。

### 6.4 方法论升级
6. **谈判系统方法**（BATNA、锚定、让步设计、利益交换）——8.6 谈判是"第一次上桌"，缺系统框架。
7. **消费者心智/品类管理**（品类角色、价格带、消费者决策路径）——理解"为什么钙D要组合卖"背后的原理。

### 6.5 数字化工具
8. **美团/京东 O2O 投流、小红书/达人种草、私域社群运营**——线上增量这半块你参与得最少。

## 七、一句话总结这套业务逻辑

> **选蓝海品类（干眼/肛肠/骨健康）→ 大单品切入 → 学术建立心智 → 政策+资源撬动连锁 → 三级矩阵落地动销 → 渠道管控护住价格 → 标杆门店复制放大 → 数据复盘迭代。**

你现在掌握的是"落地动销"和"数据复盘"两环，最缺的是"选品判断"和"财务测算"这两环——这恰好也是从"执行者"走向"操盘手"的关键一步。
